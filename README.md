# sharpa-avatar-ae01-firmware

Embedded firmware for the Sharpa AE01 Glove, supporting sensor data acquisition, tactile feedback, wired USB and 2.4 GHz wireless communication, and device operation.

---

## 📥 Download

Download the latest `.pkg` firmware package from
[Releases](https://github.com/sharpa-robotics/sharpa-avatar-ae01-firmware/releases).

For previous versions, browse the release history.

---

## 🚀 Upgrade

Use the Firmware Upgrade feature in the Avatar app to load the `.pkg` firmware file and perform the upgrade.
